<h1 align="center">
Kitchen Cleanliness Prediction using Multimodal AI
</h1>

<p align="center">
Multimodal kitchen cleanliness monitoring module integrated into DepaYT.
</p>

---

<h2>Project Overview</h2>

<p>
This project implements a multimodal artificial intelligence module integrated into the <strong>DepaYT</strong> mobile platform inside the <strong>Kitchen Usage</strong> module.
</p>

<p>
The system combines:
</p>

<ul>
    <li>Computer Vision using Convolutional Neural Networks (CNNs)</li>
    <li>Contextual reasoning using a Multilayer Perceptron (MLP)</li>
    <li>Multimodal decision fusion</li>
    <li>Context-aware recommendation generation</li>
    <li>Collaborative kitchen monitoring for shared apartment environments</li>
</ul>

<p>
The objective of the module is to assist roommates in maintaining shared kitchen cleanliness through multimodal contextual analysis and visual kitchen inspection.
</p>

---

<h2>Multimodal Workflow</h2>

<h3>1. Start Kitchen Usage</h3>

<p>
The workflow begins when a user presses the <strong>Start Usage</strong> button inside the DepaYT application before using the kitchen.
</p>

<p>
At this stage, the system starts a cooking session associated with the current user.
</p>

---

<h3>2. Stop Kitchen Usage</h3>

<p>
After finishing the cooking activity, the user presses the <strong>Stop Usage</strong> button.
</p>

<p>
Once the session ends, the application displays:
</p>

<ul>
    <li>A contextual cooking questionnaire</li>
    <li>An image upload interface for the kitchen state before cleaning</li>
</ul>

---

<h3>3. Contextual Questionnaire Processing</h3>

<p>
The user answers contextual questions describing the cooking activity performed.
</p>

<p>
The questionnaire includes information such as:
</p>

<ul>
    <li>Type of food prepared</li>
    <li>Cooking method</li>
    <li>Oil usage</li>
    <li>Spill occurrence</li>
    <li>Number of utensils used</li>
    <li>Number of people served</li>
</ul>

<p>
The answers are transformed into structured tabular data and processed by a <strong>Multilayer Perceptron (MLP)</strong>.
</p>

<p>
The MLP predicts a contextual dirtiness probability distribution representing the expected cleanliness condition generated by the cooking activity.
</p>

---

<h3>4. Kitchen Image Analysis</h3>

<p>
The user uploads an image of the induction kitchen surface immediately after cooking and before cleaning.
</p>

<p>
The uploaded image is analyzed using a <strong>Convolutional Neural Network (CNN)</strong> trained for binary kitchen cleanliness classification.
</p>

<p>
The CNN predicts whether the kitchen surface visually appears:
</p>

<ul>
    <li>Clean</li>
    <li>Dirty</li>
</ul>

<p>
The visual prediction is converted into a continuous visual dirtiness score.
</p>

---

<h3>5. Multimodal Fusion</h3>

<p>
The system combines:
</p>

<ul>
    <li>The contextual dirtiness score produced by the MLP</li>
    <li>The visual dirtiness score produced by the CNN</li>
</ul>

<p>
A weighted multimodal fusion strategy is applied to generate a final kitchen dirtiness score:
</p>

<pre><code>final_score =
    alpha * visual_score +
    (1 - alpha) * contextual_score
</code></pre>

<p>
This allows the system to combine:
</p>

<ul>
    <li>Contextual cooking information</li>
    <li>Visual cleanliness evidence</li>
</ul>

<p>
inside a unified multimodal decision-making pipeline.
</p>

---

<h3>6. Recommendation Generation</h3>

<p>
Based on the multimodal fusion result, the system generates contextual cleaning recommendations.
</p>

<p>
The recommendation engine considers:
</p>

<ul>
    <li>Predicted dirtiness level</li>
    <li>Oil usage</li>
    <li>Spill occurrence</li>
    <li>Cooking method</li>
    <li>Visual kitchen condition</li>
</ul>

<p>
The recommendations guide users in properly cleaning the kitchen after use.
</p>

---

<h3>7. Shared Kitchen Monitoring</h3>

<p>
The final cleanliness prediction and contextual session information are stored inside the application database.
</p>

<p>
All roommates can later visualize:
</p>

<ul>
    <li>Kitchen cleanliness status</li>
    <li>Previous kitchen sessions</li>
    <li>Cleaning history</li>
    <li>Shared kitchen conditions</li>
</ul>

---

<h2>Model Architectures</h2>

<h3>Image Modality</h3>

<ul>
    <li>Convolutional Neural Networks (CNNs)</li>
    <li>Transfer Learning experiments using MobileNetV3</li>
    <li>Autoencoder experiments for anomaly detection</li>
    <li>Binary kitchen cleanliness classification</li>
</ul>

---

<h3>Contextual Modality</h3>

<ul>
    <li>Multilayer Perceptron (MLP)</li>
    <li>Structured contextual questionnaire processing</li>
    <li>One-Hot Encoding preprocessing pipeline</li>
    <li>Contextual dirtiness estimation</li>
</ul>

---

<h3>Fusion Layer</h3>

<ul>
    <li>Weighted multimodal decision fusion</li>
    <li>Continuous dirtiness scoring</li>
    <li>Hybrid recommendation engine</li>
</ul>
